# UI 描述统一架构

扫描源码形成的页面规范和根据 PRD 生成的 UI 描述必须使用同一套层级。输出顺序固定为“为什么存在 → 页面全貌 → 布局骨架 → 区域 → 组件实例 → 流程与状态”，不得从零散组件直接开始。

## 一、三层知识模型

### 1. 组件能力

组件知识描述设计语义中的组件类型，不记录工程实现名。每个组件至少说明：

- 解决什么交互问题。
- 适用于什么用户目标、对象规模、任务阶段和风险条件。
- 什么情况下不应使用，应换成什么能力。
- 在不同场景中承担什么角色，是必需、条件出现还是不建议出现。
- 与其他组件怎样组合、谁先谁后、谁控制谁、谁反馈谁。
- 内容、布局、交互和状态规则。

组件不能脱离场景成为孤立清单。源码中同名组件的存在不能证明它只有一种设计语义；多个工程组件也可能归入同一种设计能力。

### 2. 场景配方

场景知识负责把用户任务转换为组件搭配。每个场景至少说明：

- 用户、触发条件、目标、对象范围、任务阶段、风险与完成结果。
- 适用与不适用边界。
- 推荐页面形态及选择理由。
- 必需组件、条件组件和应避免的组件；逐项说明角色、出现位置、出现条件和选择理由。
- 用户任务顺序、关键状态、前后场景和设计边界。

场景配方只表达稳定的组合规律，不代替具体页面蓝图。相同场景在不同业务模块中可以有不同文案和内容密度，但组件角色与任务顺序应能解释这些差异。

场景不是预置模板。必须先读取目标项目中的页面任务、真实组件组合和状态分支，再生成场景及其分组；通用 UI 分类只能用于扫描后的比较，不能在初始化阶段写入知识库。

### 3. 页面蓝图

页面蓝图还原一个真实页面，或描述一个 PRD 对应的新页面。必须从大到小展开：

1. 页面定位：为谁、在什么入口、完成什么任务、对应哪些场景。
2. 页面全景：应用外壳、导航关系、内容画布、主次区域、滚动与覆盖层策略。
3. 布局骨架：上下或左右结构、列关系、区域顺序、对齐、占用空间和固定/流动关系。
4. 区域明细：每个区域的位置、目的、优先级、内部布局、与相邻区域的关系。
5. 组件实例：组件类型、承担角色、内容、位置、尺寸或伸缩方式、交互、出现条件和局部状态。
6. 任务流程：用户视线和操作从哪里开始，如何跨区域完成任务。
7. 页面状态：触发条件、哪些区域和组件变化、保留什么上下文、如何恢复。
8. 适配与边界：不同可用空间下的重排、收纳、固定和降级规则，以及证据不足项。

## 二、组件命名边界

可见文档可以使用设计师能理解的中文组件类型，例如“页面标题”“条件输入”“结果列表”“状态标签”“主要行动”“分页导航”“确认对话框”和“侧向详情区”。不得出现源码组件名、属性、事件、文件路径、框架术语或代码片段。

组件描述必须包含业务角色，不能只写“这里有一个按钮”或“这里放一个表格”。推荐写法是：“结果区右上方的页面级主要行动，用于创建新对象；仅在用户具备创建权限时出现。”

## 三、尺寸与视觉证据

- 源码或运行页面能确认的宽度、间距、对齐、栅格、固定方式和响应式阈值，可以作为现状观察记录。
- 无法确认的具体像素、颜色、字号和品牌样式不得猜测，写为“未确认”并说明需要怎样核对。
- 运行页面观察和源码规则冲突时并列保留，不用其中一方静默覆盖另一方。
- 组件出现次数只能提高“常见程度”的证据，不能自动升级为正式规范。

## 四、PRD 生成顺序

根据 PRD 生成 UI 描述时按以下顺序推导：

1. 归一化用户目标、对象范围、任务阶段、上下文、时长、风险、结果、权限和异常。
2. 选择一个主场景，补充必要的前置、辅助、反馈和恢复场景。
3. 合并这些场景的组件配方，处理重复、条件和冲突；不能把所有候选组件无差别堆入页面。
4. 选择页面形态，把组件分配到具有明确目的的区域。
5. 生成从页面全景到组件实例的页面蓝图。
6. 补全任务流、状态变化、适配规则、设计边界和待确认项。

PRD 回答使用以下固定标题；某项证据不足时保留标题并写明未知，不能直接省略：

1. `需求与场景判断`
2. `页面全景`
3. `布局骨架`
4. `区域与组件搭配`
5. `组件使用明细`
6. `任务流程`
7. `关键状态`
8. `适配、边界与待确认`

## 五、完整性检查

一份合格的源码页面规范或 PRD UI 描述应能回答：

- 不看源码时，设计师能否画出页面的大致骨架？
- 能否区分应用导航、页面内容、主任务区域和辅助区域？
- 每个可见组件是否有业务角色、位置和出现条件？
- 组件搭配能否回到明确的任务场景，而不是凭经验拼装？
- 初始、加载、空、失败、权限受限、部分成功等相关状态是否说明了区域级变化？
- 未确认的尺寸、视觉或运行时行为是否被明确标出？

任一答案为“不能”时，该页面或 PRD 描述仍不完整。

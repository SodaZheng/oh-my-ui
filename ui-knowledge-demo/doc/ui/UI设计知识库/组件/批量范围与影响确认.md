# 批量范围与影响确认

> 持续解释哪些对象将被共同处理、哪些被排除以及操作后果。

**知识状态：** 候选规律　 **可信度：** 低

## 解决的问题

在批量执行前让用户确认真实影响范围和不可处理对象。

## 适用场景

- 多个对象执行相同操作。
- 用户能够确认共同影响。

## 不适用场景

- 每个对象需要不同输入或单独判断。
- 影响范围无法可靠预览。

## 在任务场景中的角色

- **多对象批量处理与长任务跟踪**：承载选择范围、共同操作和影响预览；出现条件：从对象集合进入批量任务时

## 与其他组件的组合关系

- 与 **[状态反馈与恢复](../组件/状态反馈与恢复.md)** 提交后由状态反馈持续解释进度和结果范围；条件：任务不能即时完成或可能部分失败时

## 内容规则

- 同时说明选择来源、数量和排除项。
- 风险说明具体到对象范围和后果。

## 布局规则

- 范围信息在选择、确认和执行阶段持续可见。
- 共同操作只在范围明确后进入主要位置。

## 交互规则

- 范围变化后重新计算影响。
- 没有选择对象时不制造可执行假象。

## 组件状态

- **范围含不可处理对象**：分开说明可处理和排除对象。

# 页面形态索引

> 页面形态是从场景正文派生的辅助入口，不再维护独立规范。完整布局、状态和选择理由以场景为准。

| 页面形态 | 解决的问题 | 关联场景 | 项目实例数 |
|---|---|---|---|
| 集合浏览工作台 | 页面以结果区域为主体；任务名称和主要行动在上方，常用条件紧随其后，结果概况连接条件与主要内容。 | [条件查找与结果浏览](场景/查找与结果浏览.md#条件查找与结果浏览) | 1 |
| 单对象任务页 | 对象身份、状态和主要行动首先可见；核心详情占主空间，历史、关联和风险作为辅助上下文出现。 | [单对象详情与状态处理](场景/单对象查看与处理.md#单对象详情与状态处理)、[分步骤创建与编辑](场景/创建与编辑.md#分步骤创建与编辑)、[基于依据的审核与决定](场景/审核与决策.md#基于依据的审核与决定) | 0 |
| 独立任务处理空间 | 页面围绕选择范围、共同操作、影响确认和任务状态展开；提交后提供稳定的返回入口和结果摘要。 | [多对象批量处理与长任务跟踪](场景/批量与异步处理.md#多对象批量处理与长任务跟踪) | 0 |
| 结果与恢复空间 | 结果摘要首先说明总体发生了什么；异常范围和原因随后展开；恢复行动紧邻可恢复对象，同时保留返回上游任务的路径。 | [失败、部分成功与恢复](场景/异常与结果反馈.md#失败、部分成功与恢复) | 1 |

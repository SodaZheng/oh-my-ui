# 待确认事项

> 证据不足、存在冲突或需要团队做规范选择的内容统一放在这里，不伪装成确定规则。

## 批量任务何时需要独立空间

应根据处理时长、风险、对象数量还是结果复杂度决定离开原页面？

**为什么需要确认：** 会改变批量任务是在集合浏览页面内完成，还是进入独立任务空间。

**建议核对方式：** 结合真实业务任务和失败结果核对，不预设固定数量阈值。

## 创建与编辑是否必须分步骤

真实业务输入是否存在明确依赖和中途保存需求？

**为什么需要确认：** 会决定使用连续页面还是阶段化任务结构。

**建议核对方式：** 观察真实页面、填写时长和中断成本，再确认页面形态。

## 演示规则尚未获得人工确认

哪些候选规律应升级为团队正式设计规范？

**为什么需要确认：** 当前内容只能辅助讨论，不能强制约束新需求。

**建议核对方式：** 由设计、产品和业务负责人结合真实证据逐项确认。
